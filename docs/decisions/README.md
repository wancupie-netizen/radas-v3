# RADAS V3 Architecture Decision Records

This directory contains durable decisions that affect RADAS V3 product scope, architecture, security, cost or operations.

## Status values

- `PROPOSED`
- `ACCEPTED`
- `SUPERSEDED`
- `REJECTED`

## Naming

Use sequential files:

```text
ADR-0001-short-decision-name.md
ADR-0002-short-decision-name.md
```

## Required sections

Each ADR must contain:

- status
- context
- decision
- consequences
- alternatives considered
- links to roadmap phase or evidence
